# 準備資訊清單

在執行安裝前，請依照本文件收集所有必要的設定值。Claude Code 會逐一詢問您每個項目，填寫完畢後自動寫入 `config/.env`。

**預計填寫時間**：10~20 分鐘（主要時間花在申請 LINE Messaging API Channel）

---

## 一、LINE Messaging API 設定

### 申請步驟

1. 前往 [LINE Developers Console](https://developers.line.biz/console/)，使用 LINE 帳號登入
2. 建立一個 **Provider**（如果還沒有的話）
3. 在 Provider 下建立新的 **Channel**，類型選擇 **Messaging API**
4. 填寫 Channel 基本資訊（名稱、說明、類別）

### 需要收集的值

#### `LINE_CHANNEL_ACCESS_TOKEN`（長期存取 Token）

- **用途**：API Server 用此 Token 呼叫 LINE API 傳送訊息給用戶
- **取得位置**：
  1. 進入您的 Messaging API Channel 設定頁
  2. 點選「**Messaging API**」分頁
  3. 滾動到「**Channel access token**」區塊
  4. 點選「**Issue**」按鈕產生長期 Token
- **格式**：約 170 個字元的字串，以 `eyJ` 開頭

#### `LINE_CHANNEL_SECRET`（Channel Secret）

- **用途**：驗證 LINE 傳來的 Webhook 請求簽章（安全驗證用）
- **取得位置**：
  1. 進入您的 Messaging API Channel 設定頁
  2. 點選「**Basic settings**」分頁
  3. 找到「**Channel secret**」欄位
- **格式**：32 個字元的十六進位字串

### LINE Webhook 後續設定（安裝完成後執行）

安裝完成並取得 ngrok 域名後，需在 LINE Developers Console 完成以下設定：

1. 進入 Messaging API Channel → 「**Messaging API**」分頁
2. 找到「**Webhook settings**」區塊
3. **Webhook URL** 填入：`https://<您的ngrok域名>/webhook/line`
4. 點選「**Verify**」確認連線成功
5. 開啟「**Use webhook**」開關（切換為啟用）

### 建議開啟的選項

| 選項 | 建議狀態 | 說明 |
|------|----------|------|
| Use webhooks | 開啟 | 讓 LINE 將訊息推送到您的 Server |
| Allow bot to join group chats | 依需求 | 若要在群組中使用 Bot 才需開啟 |
| Auto-reply messages | 關閉 | 避免 LINE 預設回覆與 Bot 回覆衝突 |
| Greeting messages | 關閉 | 避免自動問候訊息干擾 |

## 二、ngrok 設定

### 申請步驟

1. 前往 [ngrok 官網](https://ngrok.com/) 免費註冊帳號
2. 登入後進入 [Dashboard](https://dashboard.ngrok.com/)
3. 在左側選單找到「**Your Authtoken**」複製 token
4. 申請靜態域名：左側選單 → **Domains** → **New Domain**（免費版限 1 個）

### 需要收集的值

#### `NGROK_AUTHTOKEN`

- **用途**：ngrok 客戶端認證，必須設定才能使用 ngrok 服務
- **取得位置**：https://dashboard.ngrok.com/get-started/your-authtoken
- **格式**：約 50 個字元的字串，格式如 `2abc...xyz_xxxxx`

#### 靜態域名（Static Domain）

- **用途**：避免每次重啟 ngrok 後域名改變，需重新設定 LINE Webhook URL
- **取得位置**：https://dashboard.ngrok.com/domains → New Domain
- **格式**：類似 `sparkling-frog-freely.ngrok-free.app`
- **注意**：免費版限 1 個靜態域名，若無靜態域名可使用動態域名（但每次重啟需重設 LINE Webhook）

### ngrok 設定方式

安裝 ngrok 後，執行以下指令設定 authtoken（只需執行一次）：

```bash
ngrok config add-authtoken <您的NGROK_AUTHTOKEN>
```

### 使用靜態域名啟動 ngrok

```bash
# 使用靜態域名（推薦）
ngrok http --domain=<您的靜態域名> 8765

# 使用動態域名（每次啟動域名會改變）
ngrok http 8765
```

## 三、PostgreSQL 設定

以下為預設值，若無特殊需求可直接使用。**強烈建議修改密碼**，尤其是將來部署到 VPS 時。

| 變數名稱 | 預設值 | 說明 |
|----------|--------|------|
| `POSTGRES_HOST` | `localhost` | Docker 映射到本機，通常不需修改 |
| `POSTGRES_PORT` | `65432` | 預設使用 65432（非標準 5432，避免衝突）|
| `POSTGRES_DB` | `vectordb` | 資料庫名稱 |
| `POSTGRES_USER` | `testuser` | 資料庫用戶名 |
| `POSTGRES_PASSWORD` | `testpwd` | **請修改為強密碼！** |

> 若修改了預設的用戶名或密碼，請同時修改 `docker_postgreSQL/docker-compose.yml` 中對應的環境變數，確保一致。

## 四、Ollama 設定

以下為預設值，本地安裝通常無需修改：

| 變數名稱 | 預設值 | 說明 |
|----------|--------|------|
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Ollama API 服務位址 |
| `OLLAMA_CHAT_MODEL` | `qwen2.5:7b-instruct-q4_0` | 問答用 LLM 模型 |
| `OLLAMA_EMBED_MODEL` | `bge-m3` | 向量化 Embedding 模型（1024 維）|

> 若您的 Ollama 安裝在另一台機器，請將 `OLLAMA_BASE_URL` 改為對應的 IP，例如 `http://192.168.1.100:11434`。

## 五、企業文件目錄設定

#### `FILES_BASE_DIR`

- **用途**：企業文件（Word、PDF、Excel 等）存放的本地資料夾路徑
- **說明**：n8n 文件匯入流程會掃描此目錄下的 `inbox/` 子資料夾
- **格式範例**：
  - Windows：`D:/職安文件` 或 `C:/Users/yourname/Documents/企業文件`
  - macOS / Linux：`/Users/yourname/documents` 或 `/home/yourname/files`
- **注意**：請使用正斜線（`/`），即使在 Windows 上也一樣

目錄結構會自動建立為：
```
<FILES_BASE_DIR>/
├── inbox/        ← 放入待處理的新文件
├── processing/   ← 處理中（自動管理）
├── processed/    ← 已處理完成
└── error/        ← 處理失敗的文件
```

## 六、n8n 設定

n8n 不需要在 `.env` 設定，但安裝時需注意：

| 項目 | 說明 |
|------|------|
| 管理介面 | 安裝後在瀏覽器開啟 `http://localhost:5681` |
| 首次設定 | 需建立 n8n owner 帳號（輸入 email + 密碼）|
| Workflow 匯入 | 從「Import from file」匯入 `workflows/qa_workflow.json` |

> n8n 帳號密碼請自行記錄，本系統不儲存此資訊。

## 完整 .env 範本

以下是 `config/.env` 的完整範本。請複製後填入您的實際值，儲存到專案的 `config/.env` 路徑。

```dotenv
# ============================================================
# AI 企業問答助理 — 環境設定檔
# 警告：此檔案包含敏感資訊，請勿 commit 到版本控制系統！
# ============================================================

# ----------------------------
# LINE Messaging API
# ----------------------------
LINE_CHANNEL_ACCESS_TOKEN=          # 從 LINE Developers Console 取得的長期 Token
LINE_CHANNEL_SECRET=                # 從 LINE Developers Console 取得的 Channel Secret

# ----------------------------
# ngrok
# ----------------------------
NGROK_AUTHTOKEN=                    # 從 ngrok Dashboard 取得的 Authtoken
NGROK_STATIC_DOMAIN=               # 靜態域名（如：sparkling-frog-freely.ngrok-free.app）
                                    # 若無靜態域名請留空

# ----------------------------
# PostgreSQL
# ----------------------------
POSTGRES_HOST=localhost
POSTGRES_PORT=65432
POSTGRES_DB=vectordb
POSTGRES_USER=testuser
POSTGRES_PASSWORD=testpwd           # 強烈建議修改為強密碼

# ----------------------------
# Ollama（本地 LLM）
# ----------------------------
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_CHAT_MODEL=qwen2.5:7b-instruct-q4_0
OLLAMA_EMBED_MODEL=bge-m3

# ----------------------------
# 企業文件目錄
# ----------------------------
FILES_BASE_DIR=                     # 企業文件存放路徑，如：D:/職安文件

# 子目錄（通常由系統自動設定，無需修改）
INGEST_INBOX_DIR=${FILES_BASE_DIR}/inbox
INGEST_PROCESSING_DIR=${FILES_BASE_DIR}/processing
INGEST_PROCESSED_DIR=${FILES_BASE_DIR}/processed
INGEST_ERROR_DIR=${FILES_BASE_DIR}/error

# ----------------------------
# API Server
# ----------------------------
API_SERVER_PORT=8765                # Python API Server 的監聽 port
API_SERVER_HOST=0.0.0.0

# ----------------------------
# 問答參數
# ----------------------------
QA_TOP_K=5                          # 向量搜尋回傳的最相似段落數量
QA_MIN_SIMILARITY=0.7               # 最低相似度閾值（0~1，越高越嚴格）
DEFAULT_NO_ANSWER_MESSAGE=很抱歉，我在知識庫中找不到與您問題相關的資訊。請洽詢相關部門或確認問題後重試。

# ----------------------------
# 其他（選用）
# ----------------------------
DEFAULT_DEPARTMENT=general          # 預設部門（用於文件匯入的權限設定）
DEFAULT_ACCESS_LEVEL=view           # 預設存取層級（view / edit / admin）
```

---

## 填寫說明

填寫 `.env` 時請注意：

1. `=` 號兩側不要有空格
2. 值不需要加引號（除非值本身包含空格）
3. `#` 開頭的行是注釋，可以保留
4. 路徑請使用正斜線（`/`），Windows 也適用
5. **填寫完成後，確認 `.env` 不在 git 追蹤中**：
   ```bash
   git status
   # config/.env 不應出現在輸出中
   ```
