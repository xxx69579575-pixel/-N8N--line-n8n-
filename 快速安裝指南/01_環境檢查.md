# 環境檢查清單

在開始安裝前，請確認您的系統符合以下所有需求。Claude Code 會協助您逐項驗證並安裝缺少的工具。

---

## 硬體需求

| 項目 | 最低需求 | 建議配置 | 說明 |
|------|----------|----------|------|
| RAM | 8 GB | 16 GB 以上 | Ollama + Qwen2.5 模型執行時約需 5~6 GB |
| 磁碟空間 | 20 GB 可用 | 30 GB 以上 | Ollama 模型 ~6GB + Docker images ~3GB + 資料 |
| CPU | 支援 AVX 指令集 | 多核心現代 CPU | 近 5 年內的 Intel Core / AMD Ryzen 均支援 |
| GPU | 非必要 | NVIDIA（支援 CUDA）| 有 GPU 可大幅加速 Ollama 推論速度 |

> **確認 CPU 是否支援 AVX（Windows）**：
> ```powershell
> # PowerShell
> (Get-WmiObject -Class Win32_Processor).Description
> ```
> 或在工作管理員 → 效能 → CPU，查看右下角是否有 AVX 標示。

## 軟體需求清單

### 1. Docker Desktop（Windows / Mac）或 Docker Engine（Linux）

**用途**：運行 n8n 和 PostgreSQL 容器

**安裝**：
- Windows / macOS：https://www.docker.com/products/docker-desktop/
- Linux（Ubuntu）：
  ```bash
  curl -fsSL https://get.docker.com | sh
  sudo usermod -aG docker $USER
  ```

**驗證指令**：
```bash
docker --version
# 預期輸出範例：Docker version 26.1.4, build 5650f9b
# 需 >= 24.0

docker compose version
# 預期輸出範例：Docker Compose version v2.27.1
# 需 >= 2.0
```

> Windows 用戶：確認 Docker Desktop 已啟動（系統匣應有 Docker 圖示），且「Use WSL 2 based engine」選項已開啟。

---

### 2. Python 3.10 以上

**用途**：運行 API Server（scripts/api_server.py）

**安裝**：
- Windows：https://www.python.org/downloads/（安裝時勾選「Add Python to PATH」）
- macOS：`brew install python@3.12`
- Linux：`sudo apt install python3 python3-pip`

**驗證指令**：
```bash
python --version
# 或
python3 --version
# 預期輸出範例：Python 3.12.3
# 需 >= 3.10
```

---

### 3. Python 套件：psycopg2-binary

**用途**：Python API Server 連接 PostgreSQL 所需的驅動程式

**安裝指令**：
```bash
pip install psycopg2-binary
# 或
pip3 install psycopg2-binary
```

**驗證指令**：
```bash
python -c "import psycopg2; print('psycopg2 安裝成功，版本：', psycopg2.__version__)"
```

---

### 4. Ollama

**用途**：本地運行 Qwen2.5 LLM 和 bge-m3 Embedding 模型

**安裝**：
- 前往 https://ollama.ai/download 下載對應平台的安裝包
- Windows / macOS：執行安裝程式，完成後 Ollama 會自動在背景運行
- Linux：
  ```bash
  curl -fsSL https://ollama.ai/install.sh | sh
  ```

**驗證指令**：
```bash
ollama --version
# 預期輸出範例：ollama version is 0.3.12

# 確認 Ollama 服務正在運行
curl http://localhost:11434/api/tags
# 預期：回傳 JSON（即使模型清單為空）
```

---

### 5. Ollama 模型（需要下載，耗時較長）

**用途**：
- `qwen2.5:7b-instruct-q4_0`：問答 LLM（~4.4 GB）
- `bge-m3`：文字向量化 Embedding（~1.2 GB）

**下載指令**：
```bash
# 下載問答模型（約 4.4 GB，依網速需 10~30 分鐘）
ollama pull qwen2.5:7b-instruct-q4_0

# 下載 Embedding 模型（約 1.2 GB）
ollama pull bge-m3
```

**驗證指令**：
```bash
ollama list
# 預期輸出應包含：
# qwen2.5:7b-instruct-q4_0
# bge-m3
```

> 模型下載需要穩定的網路連線，建議先確認可正常存取 ollama.ai。

### 6. ngrok

**用途**：將本地 Python API Server（port 8765）透過 HTTPS tunnel 暴露給 LINE Webhook

**安裝**：
- 前往 https://ngrok.com/download 下載
- Windows：下載 zip 後解壓縮，將 `ngrok.exe` 放到 `C:\Windows\System32\` 或加入 PATH
- macOS：`brew install ngrok/ngrok/ngrok`
- Linux：
  ```bash
  curl -s https://ngrok-agent.s3.amazonaws.com/ngrok.asc | sudo tee /etc/apt/trusted.gpg.d/ngrok.asc >/dev/null
  echo "deb https://ngrok-agent.s3.amazonaws.com buster main" | sudo tee /etc/apt/sources.list.d/ngrok.list
  sudo apt update && sudo apt install ngrok
  ```

**驗證指令**：
```bash
ngrok --version
# 預期輸出範例：ngrok version 3.10.0
```

> 使用前需先設定 authtoken（在 Step 3 準備資訊清單時會收集）。

## 快速環境檢查指令

使用以下一行指令快速確認所有工具是否已安裝：

### Windows PowerShell 版本

```powershell
@("docker", "docker compose", "python", "ollama", "ngrok", "git") | ForEach-Object {
    $cmd = $_
    try {
        $ver = & cmd /c "$cmd --version 2>&1"
        Write-Host "[OK]  $cmd : $($ver | Select-Object -First 1)" -ForegroundColor Green
    } catch {
        Write-Host "[缺少] $cmd 尚未安裝" -ForegroundColor Red
    }
}
```

### Unix / macOS / Linux（bash）版本

```bash
for cmd in docker python3 ollama ngrok git; do
    if command -v "$cmd" &>/dev/null; then
        echo "[OK]  $cmd: $($cmd --version 2>&1 | head -1)"
    else
        echo "[缺少] $cmd 尚未安裝"
    fi
done

# 額外確認 docker compose（v2 寫法）
if docker compose version &>/dev/null; then
    echo "[OK]  docker compose: $(docker compose version 2>&1 | head -1)"
else
    echo "[缺少] docker compose 尚未安裝"
fi
```

## 常見問題

**Q：Docker Desktop 安裝後 `docker` 命令無效？**
A：Windows 用戶請重新開啟 Terminal（PowerShell / CMD），確認 Docker Desktop 已完整啟動（系統匣圖示變為綠色）。

**Q：`ollama pull` 下載很慢？**
A：Ollama 模型伺服器在海外，建議使用網路條件較好的時段下載，或考慮使用代理。

**Q：psycopg2 安裝失敗（Windows）？**
A：請使用 `psycopg2-binary`（非 `psycopg2`），binary 版本包含預編譯的 C 函式庫，不需要本機編譯環境。

**Q：ngrok 免費版有什麼限制？**
A：免費版每個帳號可申請 1 個靜態域名（Static Domain），這對本專案已足夠。動態域名每次重啟會變更，需重新設定 LINE Webhook URL。
