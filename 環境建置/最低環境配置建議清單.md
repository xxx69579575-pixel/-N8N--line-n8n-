# 本地 AI 企業問答助理 — 最低環境配置建議清單

> 適用於：n8n + Ollama (Qwen2.5 + bge-m3) + PostgreSQL/pgvector + LINE Messaging API

---

## 一、硬體最低需求

| 項目 | 最低規格 | 建議規格 | 說明 |
|------|----------|----------|------|
| **CPU** | 8 核心 | 12 核心以上 | Ollama 無 GPU 時以 CPU 推理，核心越多越快 |
| **RAM** | 16 GB | 32 GB | Qwen2.5:7B (Q4) 約佔 5-6 GB，系統 + n8n + Docker 約需另外 6-8 GB |
| **儲存空間** | 50 GB SSD | 100 GB SSD 以上 | 模型檔 bge-m3 ~1.2 GB、Qwen2.5:7B ~4.5 GB、Docker volumes、文件庫 |
| **GPU（選配）** | 無 | NVIDIA 8 GB VRAM 以上 | 有 GPU 推理速度提升 5-10 倍；無 GPU 仍可運行但較慢 |
| **網路** | 固定 IP 或穩定寬頻 | 固定 IP + 上行 10 Mbps | LINE Webhook 需要穩定連線；Cloudflare Tunnel 可替代固定 IP |

---

## 二、作業系統

| 選項 | 支援狀況 | 備註 |
|------|----------|------|
| **Windows 11 Pro** | 完整支援 | 需開啟 WSL2 或直接使用 Docker Desktop |
| **Ubuntu 22.04 LTS** | 完整支援（推薦伺服器用） | 資源佔用較低，穩定性佳 |
| **macOS 13+（Apple Silicon）** | 完整支援 | Ollama 原生支援 Metal GPU 加速 |

## 三、必要軟體清單

| 軟體 | 版本需求 | 用途 |
|------|----------|------|
| **Docker Desktop** | 4.x 以上 | 運行 PostgreSQL + pgvector + pgAdmin + n8n |
| **Docker Compose** | v2.x | 容器編排（含於 Docker Desktop） |
| **Ollama** | 最新版 | 本地 LLM 推理引擎 |
| **Python** | 3.10 以上 | 執行 embed_chunks / vector_search / api_server 等腳本 |
| **pip 套件** | 見下方 | Python 依賴 |
| **Node.js**（選配） | 18 以上 | 若需自行編譯 n8n 或使用相關工具 |
| **Cloudflare Tunnel** | 最新版 (`cloudflared`) | 將本機 n8n 暴露為公開 HTTPS（供 LINE Webhook 使用） |

## 五、Docker 容器配置

| 容器 | Image | Port | 用途 |
|------|-------|------|------|
| **PostgreSQL + pgvector** | `ankane/pgvector` | 65432 | 向量知識庫 |
| **pgAdmin** | `dpage/pgadmin4` | 5050 | 資料庫管理介面 |
| **n8n** | `n8nio/n8n` | 5681 | 工作流引擎 |

> Docker 建議配置至少 **8 GB RAM** 給 Docker Engine 使用（Docker Desktop → Settings → Resources）

---

## 六、網路需求

| 項目 | 說明 |
|------|------|
| **對外 HTTPS** | LINE Webhook 強制要求 HTTPS；使用 Cloudflare Tunnel 免費解決 |
| **Cloudflare Tunnel** | 執行 `cloudflared tunnel --url http://localhost:5681` 即可取得臨時 HTTPS URL |
| **固定 Tunnel（正式環境）** | 建立 Named Tunnel，URL 固定不變，避免每次重啟都要重設 LINE Webhook |
| **防火牆** | 開放本機 port：5681（n8n）、8765（api_server）、11434（Ollama）、65432（PostgreSQL） |

---

## 七、LINE 開發者設定

| 項目 | 說明 |
|------|------|
| **LINE Developers 帳號** | 需申請 Messaging API Channel |
| **Channel Access Token** | 填入 n8n 工作流 LINE Reply 節點 |
| **Channel Secret** | 填入 api_server / line_verify.py 做簽章驗證 |
| **Webhook URL** | 設定為 Cloudflare Tunnel URL + `/webhook/line-qa` |

## 八、資料庫初始化

```bash
# 啟動 Docker 容器
cd docker_postgreSQL
docker compose up -d

# 建立完整 Schema（5 張主表 + 觸發器）
psql -h localhost -p 65432 -U testuser -d vectordb \
  -f n8n自動存入資料庫/02_postgresql_schema.sql
```

---

## 九、服務啟動順序

```
1. 啟動 Docker（PostgreSQL + pgAdmin + n8n）
2. 啟動 Ollama
3. 啟動 api_server.py（python scripts/api_server.py）
4. 啟動 Cloudflare Tunnel
5. 確認 LINE Webhook URL 設定正確
```

## 十、預估資源佔用（閒置狀態）

| 服務 | RAM 佔用 |
|------|----------|
| Ollama（模型載入後） | ~5-6 GB |
| Docker（n8n + PostgreSQL + pgAdmin） | ~1.5-2 GB |
| api_server.py | < 50 MB |
| 作業系統本身 | ~2-3 GB |
| **合計** | **~9-11 GB** |

> 因此建議最低 **16 GB RAM**，32 GB 可穩定運行並保有餘裕。
